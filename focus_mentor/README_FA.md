# Focus Mentor / منتور تمرکز

یک برنامه دسکتاپ ویندوزی که مانند یک منتور کاری عمل می‌کند و به شما کمک می‌کند در طول روز روی **یک پروژه اصلی از پیش تعیین‌شده** متمرکز بمانید.

## ویژگی‌های اصلی

- 🔒 **قفل پروژه روزانه**: هر روز با انتخاب یک پروژه اصلی شروع می‌شود و تا پایان روز قفل می‌ماند
- 🎯 **مداخله هوشمند**: تشخیص فعالیت‌های حواس‌پرتی و نمایش هشدار منطقی و محترمانه
- 📊 **گزارش‌گیری**: گزارش پایان روز و هفته با آمار دقیق تمرکز
- ⏱️ **تایمر کاری**: پشتیبانی از حالت آزاد و Pomodoro
- ⏸️ **Pause موقت**: امکان توقف موقت پایش با محدودیت زمانی
- ⚙️ **تنظیمات انعطاف‌پذیر**: لیست سفید/سیاه قابل ویرایش، آستانه‌های زمانی قابل تنظیم
- 🔐 **حریم خصوصی**: فقط نام برنامه و عنوان پنجره پایش می‌شود - هیچ محتوایی ذخیره نمی‌گردد

## نصب

### پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- پایتون ۳.۸ یا بالاتر

### مراحل نصب

۱. کلون کردن یا دانلود پروژه:
```bash
cd focus_mentor
```

۲. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

۳. اجرای برنامه:
```bash
python main.py
```

### نکته مهم

برای عملکرد کامل برنامه، کتابخانه `pywin32` ضروری است. اگر هنگام اجرا خطا دریافت کردید:

```bash
pip install --upgrade pywin32
```

## راهنمای استفاده

### شروع روز کاری

۱. پس از اجرای برنامه، آیکون آن در System Tray (کنار ساعت ویندوز) ظاهر می‌شود.
۲. روی آیکون کلیک راست کرده و **"شروع روز کاری"** را انتخاب کنید.
۳. فرم Daily Lock-in باز می‌شود. اطلاعات زیر را وارد کنید:
   - **نام پروژه امروز** (الزامی)
   - **هدف مشخص امروز** (الزامی)
   - مدت‌زمان تقریبی کار (اختیاری)
   - ابزارهای اصلی مورد نیاز (اختیاری)
   - فعالیت‌هایی که نباید منحرف شوید (اختیاری)

۴. روی **"شروع روز کاری"** کلیک کنید. پروژه قفل شده و پایش آغاز می‌شود.

### منوی System Tray

| گزینه | توضیح |
|-------|-------|
| شروع روز کاری | نمایش فرم قفل پروژه (فقط وقتی روز کاری شروع نشده) |
| پایان روز کاری | ثبت پایان روز و نمایش گزارش |
| Pause موقت | توقف موقت پایش (۱۰ دقیقه پیش‌فرض) |
| ادامه | بازگشت از حالت Pause |
| مشاهده گزارش امروز | نمایش آمار و اطلاعات روز جاری |
| تنظیمات | باز کردن پنجره تنظیمات |
| خروج | بستن برنامه |

### نحوه کار مداخله

وقتی برنامه تشخیص دهد شما برای مدت مشخصی روی یک برنامه/سایت مشکوک هستید:

۱. یک پنجره overlay نمایش داده می‌شود
۲. پیام منطقی و محترمانه‌ای درباره انحراف از هدف امروز نشان داده می‌شود
۳. دو گزینه دارید:
   - **"بله، بخشی از کار اصلی است"**: باید دلیل کوتاهی بنویسید
   - **"نه، برگردم به کار اصلی"**: overlay بسته شده و پیام تشویقی نمایش داده می‌شود

### محدودیت نرخ مداخله

برای جلوگیری از آزار بیش از حد:
- حداکثر ۳ overlay در هر ۳۰ دقیقه
- اگر زیاد از حد "بخشی از کار اصلی است" را انتخاب کنید، هشدار تحلیلی نمایش داده می‌شود

## تنظیمات

### تب عمومی

- **حالت تایمر**: Free یا Pomodoro
- **مدت زمان Pause**: ۱ تا ۳۰ دقیقه
- **حداکثر تغییر پروژه در روز**: تعداد مجاز تغییر پروژه

### تب لیست سفید

برنامه‌هایی که همیشه مجاز هستند:
- به صورت پیش‌فرض: illustrator.exe, photoshop.exe, figma.exe, ...
- می‌توانید موارد جدید اضافه یا حذف کنید

### تب لیست سیاه نرم

برنامه‌هایی که پس از مدتی هشدار می‌دهند:
- به صورت پیش‌فرض: chrome.exe, youtube.com, instagram.com, ...
- می‌توانید موارد جدید اضافه یا حذف کنید

### تب آستانه‌ها

- **آستانه زمانی برای ابزارهای مشکوک**: ۱۰ تا ۱۸۰ ثانیه (پیش‌فرض: ۲۰)
- **آستانه زمانی برای ابزارهای ناشناخته**: ۱۰ تا ۳۰۰ ثانیه (پیش‌فرض: ۹۰)
- **حداکثر تعداد overlay در هر ۳۰ دقیقه**: ۱ تا ۱۰ (پیش‌فرض: ۳)

## محل ذخیره داده‌ها

داده‌ها در پوشه‌ای به نام `focus_mentor_data` در کنار فایل اجرایی ذخیره می‌شوند:

```
focus_mentor_data/
├── daily_projects.json      # پروژه‌های روزانه
├── window_events.json       # رویدادهای پنجره
├── interventions.json       # مداخله‌ها
├── project_switches.json    # تغییرات پروژه
├── pause_events.json        # رویدادهای Pause
├── daily_reports.json       # گزارش‌های روزانه
├── weekly_reports.json      # گزارش‌های هفتگی
└── settings.json            # تنظیمات کاربر
```

## حریم خصوصی

این برنامه:
- ✅ فقط نام برنامه فعال، عنوان پنجره و مدت‌زمان استفاده را ثبت می‌کند
- ❌ هیچ متن تایپ‌شده‌ای را ذخیره نمی‌کند
- ❌ هیچ محتوای صفحه‌ای را ضبط نمی‌کند
- ❌ هیچ رمز یا اطلاعات حساسی را ذخیره نمی‌کند
- ❌ هیچ اسکرین‌شات یا تصویری نمی‌گیرد
- ❌ هیچ داده‌ای به اینترنت ارسال نمی‌کند

تمام داده‌ها به صورت محلی روی سیستم شما باقی می‌مانند.

## عیب‌یابی

### مشکل: آیکون در System Tray ظاهر نمی‌شود

راه‌حل:
```bash
pip install --upgrade pystray Pillow
```

### مشکل: خطا در شناسایی پنجره‌ها

راه‌حل:
```bash
pip install --upgrade pywin32 psutil
```

سپس سیستم را ری‌استارت کنید.

### مشکل: برنامه بعد از اجرای سریع بسته می‌شود

مطمئن شوید تمام وابستگی‌ها نصب شده‌اند:
```bash
pip install -r requirements.txt
```

### مشکل: overlay نمایش داده نمی‌شود

بررسی کنید که:
1. آستانه‌های زمانی خیلی بزرگ نباشند
2. برنامه در حالت Pause نباشد
3. روز کاری شروع شده باشد

## تغییر whitelist و soft blacklist

### روش ۱: از طریق رابط تنظیمات

۱. روی آیکون System Tray کلیک راست کنید
۲. **تنظیمات** را انتخاب کنید
۳. به تب **لیست سفید** یا **لیست سیاه نرم** بروید
۴. موارد جدید اضافه یا حذف کنید

### روش ۲: ویرایش مستقیم فایل settings.json

فایل `focus_mentor_data/settings.json` را با یک ویرایشگر متن باز کنید و لیست‌ها را ویرایش کنید:

```json
{
  "whitelist": ["illustrator.exe", "figma.exe", "your_app.exe"],
  "soft_blacklist": ["chrome.exe", "youtube.com"]
}
```

## نکات تکمیلی

### بهترین روش‌های استفاده

۱. **پروژه واقع‌بینانه انتخاب کنید**: پروژه‌ای که واقعاً بتوانید در یک روز روی آن کار کنید
۲. **هدف مشخص تعریف کنید**: به جای "کار روی لوگو"، بنویسید "طراحی ۳ ایده اولیه برای لوگوی شرکت X"
۳. **ابزارهای اصلی را وارد کنید**: اگر از ابزار خاصی استفاده می‌کنید، آن را به لیست ابزارهای اصلی اضافه کنید
۴. **گزارش پایان روز را مطالعه کنید**: به هشدارهای تحلیلی توجه کنید و روز بعد بهبود ببخشید

### محدودیت‌های فنی

- برنامه فقط روی ویندوز ۱۰/۱۱ کار می‌کند
- نیاز به اتصال اینترنت ندارد (کاملاً آفلاین)
- برای شناسایی دقیق پنجره‌ها نیاز به دسترسی ادمین ندارد، اما برخی برنامه‌ها ممکن است شناسایی نشوند
- در حالت Sleep یا Hibernate، پایش متوقف می‌شود
